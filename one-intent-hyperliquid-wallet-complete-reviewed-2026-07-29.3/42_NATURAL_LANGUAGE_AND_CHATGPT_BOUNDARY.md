# 自然言語操作とChatGPT連携の境界

**版:** 2026-07-29.3  
**目的:** 「言葉で操作できる体験」を独立ウォレット内で実現しつつ、OpenAIサービスを取引の開始・実行・促進へ使わない。

## 1. 結論

自然言語による取引・送金は、独立したAndroid／iPhoneウォレットの中で提供する。取引文の解析は、決定論的な端末内処理を第一候補とし、必要な場合でも、OpenAIサービスから分離された独立運用の非OpenAIコンポーネントだけを候補にする。解析結果は常に未信頼の下書きであり、決定論Compiler、Policy、本人確認、保護Signerを通過するまで実行候補にならない。

ChatGPTのアプリ、Apps SDK、MCP、Action、外部ツールから、注文、送金、交換、出金、発行、償還を開始・実行・促進する機能は提供しない。2026-07-29時点のOpenAI App Developer Termsは、OpenAI Servicesを通じて金銭移転、暗号資産移転、金融・投資取引を開始、実行、またはその他の形で促進するAppを禁止している。本設計は「実行しない」だけでなく「取引固有の手順や事前入力で促進しない」側へ保守的に固定する。規約が将来変わっても、自動的に書き込み機能を有効にせず、法務・セキュリティ・OpenAI審査の再確認を必須とする。

## 2. ChatGPT／OpenAI側で許可する機能

機械可読な正本は `contracts/chatgpt-readonly-openapi.yaml` とし、公開可能なoperationは次の4つだけに固定する。

- `getReadOnlyStatus` — 独立ウォレット内で既に作成された不透明な参照IDについて、照合済みの抽象状態と固定message codeだけを返す
- `getPlainJapaneseTerm` — 固定された用語辞書から、やさしい日本語の一般説明を返す
- `explainNonTransactionalError` — 固定されたエラーコードについて、取引内容を含まない一般説明を返す
- `getGenericSafetyHelp` — 固定された安全トピックについて、一般的な注意だけを返す

出力は固定・版管理されたcatalogから返し、利用者の取引文をもとに自由生成しない。中立的な引継ぎ文は「独立したウォレットアプリを開いて確認してください」という一般案内だけにする。 取引固有の下書きやボタン手順も返さない。

次は、読み取り専用に見えても禁止する。

- 送金先、金額、資産、ネットワーク、売買方向、取引倍率、注文条件を含む説明や下書き
- 利用者の取引に合わせたボタン名、画面遷移、操作順序、コピー用値
- 取引固有の手動復旧手順
- quote、最低受取、手数料上限、清算価格等を取引実行へ結び付ける出力
- 署名可能な原文、署名challenge、WalletConnect要求、calldata、order payload
- 実行URL、事前入力deep link、QR、handoff token、queue ID
- 独立ウォレット側へ取引内容を事前入力、エンコード、予約、送信する仕組み
- 利用者の確認を飛ばすtokenまたは「承認済み」と誤認させる表示

ホーム画面を開く一般的なリンクであっても、取引内容、画面位置、操作ID、宛先、金額、資産、ネットワークを持たせない。

## 3. 独立ウォレット内の自然言語処理

### 3.1 取引Intent Parser

取引文は次の優先順位で解析する。

1. 端末内の決定論的parser、辞書、有限状態機械、厳格な数値・日本語正規化
2. それだけで解決できない場合は、法務・セキュリティ審査済みでOpenAIサービスから分離された独立運用の非OpenAIコンポーネント
3. どちらでも一意に決まらなければ質問へ戻し、実行しない

取引文、送金先、金額、資産・ネットワーク選択、承認情報、payload、署名材料をOpenAIサービスへ送って取引用下書きを作らない。

取引Intent Parserは次へ到達できないネットワーク構成とする。

- Signer
- 秘密鍵保管領域
- broadcast endpoint
- feature gate管理
- 任意コントラクト実行

### 3.2 任意の非取引サポートGateway

OpenAIサービスを使う任意機能を設ける場合は、取引Intent Parserと別service、別credential、別schema、別network policyにする。受け取れるのは固定の用語ID、安全トピックID、エラーコード、ロケール、取引内容を含まない不透明な状態参照IDだけである。

provider credentialはbackend secret managerで管理し、アプリへ配布しない。GatewayはSigner、Control API write、broadcast、Address Book、取引履歴、quote、Execution Capsuleへ到達できない。

### 3.3 未信頼下書きの役割

取引Intent Parserが行えるのは候補作成だけである。

- intent分類
- 金額・資産・方向・相手alias・ネットワーク候補の抽出
- 難しい言葉の言い換え
- 足りない情報の質問候補作成

取引Intent Parserが行えないことは次のとおり。

- 金額計算の最終決定
- 清算価格の計算
- 手数料交換量の決定
- 送金先アドレスの推測・生成
- 署名対象の作成
- Policy判定
- nonce割当
- 署名
- broadcast
- 再送判断
- Mainnet gate変更

### 3.4 決定論コア

未信頼の下書きを共有決定論コアで再解析し、許可された型へ変換する。決定論コアは次を固定する。

- 資産・ネットワーク・コントラクトの許可一覧
- 金額精度と丸め
- 取引方向
- 送金先登録状態
- 取引倍率上限
- 予定価格と成立価格のずれの上限
- 手数料上限
- 清算価格表示の鮮度
- Standing Authorizationの範囲
- 実行前に必要な確認強度

Parser出力に余分なフィールド、任意call data、未知資産、未登録アドレスが含まれる場合は失敗として閉じる。

### 3.5 手動復旧案内

取引固有のボタン名、画面遷移、アドレス、ネットワーク、必要量、再試行条件を含む手動復旧案内は、独立ウォレットアプリ内だけで表示する。版管理・署名済みのcatalogと、検証済みのruntime factsから決定論的に描画し、ChatGPT／OpenAI側へ公開せず、自由生成モデルに作成・変更させない。

## 4. 「最初の一回だけ承認」の意味

無期限・無制限・何でもできる包括承認にはしない。最初の設定画面で、利用者が次を個別に選び、端末認証で承認する。

- 有効期限
- 1回あたり上限
- 1日／1か月あたり上限
- 対象資産
- 対象ネットワーク
- 最大取引倍率
- 登録済み送金先
- 許可する取引種類
- ネットワーク手数料の自動準備上限
- 利用できる交換先／代理支払い先
- 失敗時の停止条件
- 通知方法

範囲内の通常操作は、独立ウォレット内の自然言語入力から下書き・検査・端末認証へ進める。次は常に個別確認とし、Standing Authorizationだけで実行しない。

- 新しい送金先
- 高額または全額送金
- 復旧
- 鍵・権限・回収先の変更
- root権限操作
- 許可していない資産・ネットワーク
- 上限の変更
- 代理支払い先の変更
- Mainnet初回利用

権限はいつでも一覧表示、停止、失効できる。期限切れ後は再承認する。

## 5. 音声入力の保護

- 音声原文と正規化結果を別に保存する。
- 「読み取った内容」を承認前に表示する。
- 同音異義語や誤変換を理由に、金額・資産・相手を補完しない。
- 「全部」「いつもの」「あれ」などは、参照対象が一意でなければ質問する。
- 周囲の音声による誤作動を防ぐため、マイク入力だけで実行状態へ移さない。
- 音声認識の信頼度は説明材料に使えるが、低信頼度だけを唯一の停止条件にしない。

## 6. プライバシー

- 取引文、住所録名、アドレス、正確な残高、取引履歴、金額、資産・ネットワーク選択をOpenAIサービスへ送らない。
- ChatGPT側の状態参照IDはランダムで不透明、短期限、読み取り専用とし、取引内容をエンコードしない。
- seed phrase、秘密鍵、署名、MPC share、完全な本人確認書類をAIへ送らない。
- 非取引サポートのログも固定field allowlistを通し、自由文、完全なアドレス、認証情報を保持しない。
- 学習利用、保持期間、第三者提供を利用者へ明示する。

## 7. 受入条件

- ChatGPT／MCP定義のoperation IDが正本4件とexact一致し、追加operation、proxy、dynamic discoveryがない。
- ChatGPT request schemaはrecipient、address、amount、asset、network、order、approval、transaction、payload、signature、deep linkを受理しない。
- ChatGPT response schemaは取引固有のsteps、buttons、values、payload、linkを持たず、`executable=false`を固定する。
- 中立的な引継ぎ文は固定文であり、取引内容をエンコードしない。
- 独立ウォレットの取引Intent ParserからOpenAI endpointへのegressがない。
- 独立ウォレット内のParser出力からSignerへ直接到達できない。
- 手動復旧catalogは独立ウォレット内だけにあり、ChatGPT contractから参照できない。
- Parserを停止しても、既存の構造化画面から手動入力・確認・実行ができる。
- 「AIが全部やりました」ではなく、どの権限と決定論ルールで何が進んだかを表示する。
- 規約変更を検知しても、法務承認なしに機能を自動有効化しない。
