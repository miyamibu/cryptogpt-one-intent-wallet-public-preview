# 手数料経路・資産登録情報の分離仕様

**版:** 2026-07-29.3  
**判定:** 設計／SchemaはGO、本番経路はNO-GO

## 1. 修正した根本問題

「JPYCを持っている」「PolygonでPOLが0」「JPYCからPOLへ交換できる」という三つの文だけでは、最初の処理を開始できるとは限らない。通常の外部所有口座では、JPYCを交換する取引自体にPOLが必要になる。さらに、代理支払い対応を名乗る画面があっても、対象口座・ネットワーク・資産・操作・費用・期限が同じ証明へ結び付いていなければ、本当に利用可能か判断できない。

そこで、以下を別々の信頼対象に分けた。

| 信頼対象 | 役割 | Schema |
|---|---|---|
| 資産登録情報 | ネットワーク、正式資産、アドレス、桁数、有効期限 | `schemas/asset-registry.schema.json` |
| 手数料経路の能力 | 口座方式、提供者、0残高開始能力、前提条件、失敗時請求 | `schemas/fee-route-capability.schema.json` |
| 今回の見積もり | 対象操作、口座、金額、nonce、上限、期限 | `schemas/fee-readiness-plan.schema.json` |
| 自動処理不能時 | 最新見積もりに基づく、人が行う具体的手順 | `schemas/manual-fallback.schema.json` |

一つのフラグだけで「手数料準備可能」としない。

## 2. 本番の資産登録情報

本番の資産登録情報には最低限、次が必要である。

- CAIP-2形式のネットワークID
- chain ID
- 手数料用資産と桁数
- JPYCのコントラクトと桁数
- 可能な場合はコードハッシュ
- 公式情報源、取得時刻、内容ハッシュ
- 登録情報の有効期限
- 署名鍵IDと署名
- 二人承認の変更履歴
- 失効と競合時の停止規則

画面例の`0x0000000000000000000000000000000000000137`は明示的なダミーであり、本番へコピーしてはならない。例には`SIMULATION_ONLY`と`productionEligible=false`を付けた。

## 3. 手数料経路の能力証明

次を証明できない経路は本番利用不可とする。

- 提供者の法人名、連絡先、規約、対象地域
- 対象ネットワーク
- 対象口座方式
- 手数料用資産が0でも開始可能か
- 必要な既存残高、許可、Permit、EntryPoint、口座工場
- 対応するJPYC登録情報
- 見積もりへ結び付ける必須項目
- 失敗時の請求方式と上限
- 証明の取得時刻、有効期限、失効状態
- 独立監査の識別子

「代理支払い対応」という文字列だけでは能力証明にならない。

## 4. 今回の見積もり

見積もりは少なくとも次へ結び付ける。

```text
account
networkId
asset
operation
amount
nonce
expiresAt
maxJpycCost
feeAssetCost
providerSettlementTarget
```

いずれかが変わった場合、再利用せず新しい見積もりを取得する。見積もりの署名状態が画面例、期限切れ、失効、照合不一致なら停止する。

## 5. 状態判定

| 状態 | 処理 |
|---|---|
| 手数料用残高が十分 | 何もしない |
| 少し不足し、通常取引を開始できる | 必要最小限＋上限付き予備だけを見積もる |
| 0残高で、対象口座の正式な経路証明が有効 | 同じ見積もりへ束縛された経路だけを使う |
| 経路証明なし／期限切れ／競合 | 手動復旧へ移る |
| 推奨入金量を対象操作に結び付けて取得不能 | 固定量を出さず停止 |

失敗後に別の提供者、別ネットワーク、別資産へ自動変更しない。

## 6. 管理者の停止条件

以下を検出した場合、対象機能または全書き込みを停止する。

- 登録情報の署名不一致
- JPYCアドレスまたはコードハッシュの競合
- 手数料経路の失効
- 見積もりの異常増加
- 失敗時請求が契約と不一致
- 同じquote IDまたはnonceの再利用
- 精算先の変更
- 月間上限超過
- 提供者障害または資金不足
- 独立監査の重大指摘

## 7. 収録例の意味

`examples/asset-registry-simulation.json`、`examples/fee-route-capability-simulation.json`、`examples/fee-readiness-jpyc-only.json`は、構造と画面見本のテスト用である。実在の提供者、正式な本番アドレス、実際の見積もり、利用可能性を表さない。
