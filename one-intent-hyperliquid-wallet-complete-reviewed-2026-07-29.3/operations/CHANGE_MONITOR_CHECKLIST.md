# Change Monitor Checklist

## Daily

- [ ] Hyperliquid official docs diff
- [ ] official GitHub commits/releases
- [ ] Bridge paused/address/code hash
- [ ] API error rate
- [ ] official X last 7 days
- [ ] exploit/scam alert

## Per release

- [ ] source pins refreshed
- [ ] signing golden vectors
- [ ] contract registry signed
- [ ] fee/minimum runtime checks
- [ ] model eval
- [ ] legal assumptions unchanged
- [ ] feature gates approved
- [ ] social/official status reviewed

## Stop conditions

- unknown action field
- SDK signature change
- Bridge code mismatch
- documentation conflict
- official warning
- unresolved security incident
- legal assumption change
